# AndThen Studio

Binaries of AndThen Studio, a local companion app for the [AndThen](https://github.com/IT-HUSET/andthen) plugin.

## Install

```bash
# macOS / Linux
curl -fsSL https://github.com/IT-HUSET/andthen-studio-releases/releases/latest/download/install.sh | sh
```

```powershell
# Windows (PowerShell)
irm https://github.com/IT-HUSET/andthen-studio-releases/releases/latest/download/install.ps1 | iex
```

Re-run the same command to update.

## Uninstall

```bash
curl -fsSL https://github.com/IT-HUSET/andthen-studio-releases/releases/latest/download/uninstall.sh | sh
```

```powershell
irm https://github.com/IT-HUSET/andthen-studio-releases/releases/latest/download/uninstall.ps1 | iex
```
